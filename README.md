# Curso: R e Python para Bioinformática Forense
## Do Zero ao Especialista em Análise e Computação Forense em Ciências da Vida

---

## 🎯 Visão Geral

Este curso completo forma especialistas em **bioinformática forense**, integrando programação em R e Python com técnicas avançadas de análise computacional aplicadas às ciências forenses. Você aprenderá desde os fundamentos das linguagens até aplicações especializadas em genômica forense, toxicologia computacional e análise de evidências biológicas.

### Para Quem é Este Curso?

- Estudantes de graduação e pós-graduação em Ciências Biológicas, Farmácia, Medicina Legal ou áreas afins
- Profissionais de laboratórios forenses que desejam automatizar análises
- Pesquisadores em bioinformática que querem aplicar suas habilidades no contexto forense
- Peritos criminais que buscam capacitação em análise computacional de dados biológicos

### Pré-requisitos

- Conhecimentos básicos de biologia molecular e genética
- Familiaridade com conceitos estatísticos (média, desvio padrão, testes de hipóteses)
- Nenhum conhecimento prévio de programação necessário — começamos do zero

## 🔬 Tópicos Abordados por Módulo

### Módulo 01: Fundamentos de R para Bioinformática
- Sintaxe básica, vetores, data frames e listas
- Pacotes tidyverse (dplyr, tidyr, ggplot2)
- Bioconductor: introdução e pacotes essenciais
- Manipulação de dados biológicos (FASTA, VCF, GFF)
- Visualização de dados genômicos
- Estatística descritiva e inferencial em R

### Módulo 02: Fundamentos de Python para Bioinformática
- Sintaxe Python, estruturas de dados e funções
- NumPy, Pandas e manipulação de dados tabulares
- Biopython: sequências, alinhamentos e bancos de dados
- Matplotlib e Seaborn para visualização científica
- Introdução ao scikit-learn para classificação biológica
- Automação de análises e pipelines

### Módulo 03: Análise Forense de Dados Biológicos
- Princípios da ciência forense e cadeia de custódia digital
- Estatística forense: likelihood ratios, pesos de evidência
- Visualização forense: padrões, outliers e anomalias
- Machine learning aplicado à classificação de amostras
- Validação de métodos computacionais forenses
- Reprodutibilidade e documentação de análises

### Módulo 04: Genômica Forense e Análise de DNA
- Marcadores STR: análise, interpretação e estatísticas
- SNPs forenses: painéis, ancestralidade e fenótipos
- Sequenciamento de nova geração (NGS) em forense
- Análise de misturas de DNA e desconvolução
- Bancos de dados genéticos e buscas familiares
- Software forense: STRait Razor, EuroForMix, DNAmixtures

### Módulo 05: Toxicologia e Metabolômica Computacional
- Espectrometria de massas: LC-MS e GC-MS
- Processamento de dados metabolômicos (XCMS, MZmine)
- Identificação de substâncias e bibliotecas espectrais
- Análise multivariada: PCA, PLS-DA, OPLS-DA
- Biomarcadores toxicológicos e assinaturas metabólicas
- Integração de dados ômicos em toxicologia forense

### Módulo 06: Projetos Práticos Integrados
- Caso 1: Análise completa de perfil genético misto
- Caso 2: Triagem toxicológica por metabolômica não-dirigida
- Caso 3: Investigação de ancestralidade e fenótipo por SNPs
- Caso 4: Pipeline automatizado de análise forense
- Elaboração de laudos técnicos e relatórios periciais
- Apresentação oral e defesa de resultados

## 🛠️ Ambiente de Desenvolvimento

### R
- R ≥ 4.3.0
- RStudio Desktop (recomendado) ou VS Code com extensão R
- Pacotes: tidyverse, Bioconductor, ggplot2, shiny, forensicTools

### Python
- Python ≥ 3.10
- Anaconda/Miniconda (recomendado) ou venv
- Pacotes: pandas, numpy, biopython, scikit-learn, matplotlib, seaborn

### Ferramentas Adicionais
- Git para controle de versão
- Docker (opcional, para reprodutibilidade)
- Jupyter Lab / RStudio Server (opcional, para ambiente web)

## ⚖️ Aspectos Éticos e Legais

Este curso aborda técnicas computacionais aplicadas à ciência forense. Todo o conteúdo é fornecido com fins **educacionais e de pesquisa**. Os alunos devem:

- Respeitar as normas éticas de suas instituições e jurisdições

- Seguir protocolos de biossegurança e proteção de dados
- Reconhecer as limitações dos métodos computacionais em contextos legais
